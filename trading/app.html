ANDROID + IPHONE / BROWSER INSTALLATION

Your learning desk.
On your home screen.

This is an installable web app—not an APK, IPA or store listing. The shell can open offline, but login, lessons and videos need the internet so access changes can be enforced.

Use your phone’s main browser to install Trade Zuko.

Android / Chrome
  1. Open this page in Chrome over HTTPS.
  2. Tap the install button if Chrome offers it, or use its menu → Install app / Add to Home screen.
  3. Open Trade Zuko from the new icon and log in.
iPhone / Safari
  1. Open this page in Safari.
  2. Tap Share (or the page menu, then Share) → Add to Home Screen.
  3. Enable Open as Web App if shown, then tap Add.
  4. Open Trade Zuko from your Home Screen and log in.
